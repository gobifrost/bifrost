# Step 0 — Current State

1. Read the item, its discussion and linked work. Use T3 read tools for T3 threads and the available PR tools for pull requests.
2. Check the current upstream implementation. Fetch `origin/main` if needed and read it with `git show origin/main:<path>` or `git grep`. A local checkout can be stale.
3. Search issues and PRs for the same outcome, including in-flight work. If the behavior is already shipped, give **already-resolved** with the implementing commit or PR. If another item tracks the same remaining work, give **duplicate** and link it.
4. If the subject is a fresh idea or local change, proceed after checking for existing coverage and ownership. If a linked item is closed or withdrawn, account for its disposition before proceeding.
