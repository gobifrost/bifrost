Run requests now use the run user's current roles and organization reach. Full workflows add all permissions within that reach; Agents and inline scripts gain no extra permissions. Before upgrading, drain queued and active runs and update the API and workers together. Review pending runs refused for a missing run user or acting user, then restart them under a valid identity. Reapprove affected Solution permission requests.
