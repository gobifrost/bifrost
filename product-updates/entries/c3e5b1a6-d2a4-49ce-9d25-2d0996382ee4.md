Zero Trust Automation checks each run against the run user's current roles and organization reach. Full Access adds every permission within that reach; Declared Permissions adds only the workflow's configured permissions. A run identity records who acts, while agents and inline scripts add no workflow powers. Before upgrading, drain queued and active runs and update the API and workers together. Review runs refused for a missing run user or acting user before restarting them under a valid identity. Reapprove affected Solution permission requests.
