Agent-specific MCP connections now use the shared discovery gateway. Refresh your client’s tool catalog; custom clients must discover tools and call `bifrost_execute_tool`, or invoke agents with `bifrost_execute_agent`. Update custom prompts that name `delegate_to_*` to use runtime-provided tools. Saved workflow restrictions migrate to stable IDs. Review [MCP Settings](/settings/mcp) if unresolved legacy blocks disabled access. With Allow All Tools off, an empty allowed list blocks all tools and agent invocations.
