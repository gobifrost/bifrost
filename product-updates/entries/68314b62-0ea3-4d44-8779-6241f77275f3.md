Self-hosted administrators: schedule maintenance for this upgrade. Block and drain API, MCP, and WebSocket traffic, then verify every serving API and MCP endpoint runs the new build. Update deployed V2 App SDKs before reopening those Apps. Everyone must sign in again in browsers, the CLI, and MCP clients. Ordinary rolling deployment and rollback below this authentication version are unsupported. The runtime legacy bridge remains supported.
