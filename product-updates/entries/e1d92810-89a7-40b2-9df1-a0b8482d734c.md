SDK workflows now reuse cached config values and database connections, reducing repeated work without new settings. The default API connection ceiling remains unchanged; each API process can retain ten more idle connections after a burst. Concurrent first writes now create one table. Installations with duplicate ad-hoc table names in one organization or global scope must resolve them before upgrading. The migration reports affected table IDs and stops without changing data.
