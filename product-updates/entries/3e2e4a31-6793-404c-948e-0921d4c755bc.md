Trusted code authors can run Python through MCP or an assigned agent tool without registering a workflow. Execute Code requires platform-administrator-level trust; it does not provide a security sandbox for untrusted Python. Existing custom-role inline-code users need an explicitly reviewed Execute Code grant in [Roles](/roles) after upgrading.
