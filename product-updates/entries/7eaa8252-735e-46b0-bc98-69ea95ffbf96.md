The scheduler and worker now run one executor that handles every job type, so an unchanged scheduler works as a second worker. RabbitMQ and KEDA are no longer used; remove them once the API logs that it drained. We recommend 2 GB per worker for most high-memory jobs and agent headroom; larger app builds may need more.

[Sizing Guide](https://github.com/gobifrost/bifrost/blob/main/docs/runbooks/kubernetes-worker-deployment.md#resource-sizing)
