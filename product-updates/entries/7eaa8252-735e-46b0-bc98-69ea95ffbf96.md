RabbitMQ is gone; the scheduler and worker now run the same executor, taking work by memory. Docker: limit both services to 2 GB (older files capped only the scheduler, at 1 GB). Kubernetes: the API starts worker Jobs (2 GiB, one warm, up to six); apply the new manifests, then delete the worker and scheduler Deployments.

[Sizing Guide](https://github.com/gobifrost/bifrost/blob/main/docs/runbooks/kubernetes-worker-deployment.md#resource-sizing)
