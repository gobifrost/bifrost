Subscribe workflows to the new user.created and user.signed_in topics in [Event Sources](/event-sources). SSO sign-ins include the identity provider's verified claims, including groups, so a workflow can keep Bifrost roles in sync. Built-in topics are now reserved for Bifrost: code that emits one, such as integration.refresh_failed, must switch to its own topic name.
