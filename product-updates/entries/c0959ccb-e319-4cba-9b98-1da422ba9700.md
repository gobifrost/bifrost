Production installations now send Bifrost a daily report by default containing a persistent random installation ID, version, and aggregate workflow and agent run counts. Reports exclude customer identities and content; development, testing, and debug instances do not report, and `BIFROST_USAGE_REPORTING_ENABLED=false` permanently opts out.
