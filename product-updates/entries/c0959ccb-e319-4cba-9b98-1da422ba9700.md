Bifrost sends anonymous usage information daily by default. It sends nothing more than:

- A persistent random installation ID
- Bifrost version
- UTC reporting day
- Workflow run count
- Agent run count
- Report format version
- Production environment marker

Development, testing, and debug instances do not report. Set `BIFROST_USAGE_REPORTING_ENABLED=false` to permanently opt out.
