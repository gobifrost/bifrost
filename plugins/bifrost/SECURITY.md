# Security Policy

The Bifrost plugin follows the
[Bifrost Security Policy](https://github.com/gobifrost/bifrost/blob/main/SECURITY.md),
which defines supported versions, response timelines, and disclosure practices.

## Report a Vulnerability

Report vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/gobifrost/bifrost/security/advisories/new).
If you cannot use GitHub, email **jackmmusick@gmail.com** with the affected
version, impact, and reproduction steps.

Do not open a public issue or include credentials in a report.
