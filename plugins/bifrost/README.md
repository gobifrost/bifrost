# Bifrost

Build automation for managed service providers with the Bifrost SDK and CLI.
This Codex plugin includes skills for workflows, forms, agents, apps, Solutions,
tables, and managed files.

## Get Started

Use the setup skill to install the CLI and connect to your Bifrost instance.
You need access to a running instance to deploy and run automation.

Example requests:

- "Set up the Bifrost CLI for my instance."
- "Build a Bifrost workflow and a form to run it."
- "Create an independent Bifrost app."

## Included Skills

| Skill | Purpose |
| --- | --- |
| Build | Create and update workflows, forms, agents, apps, Solutions, tables, and files. |
| Setup | Install the CLI, authenticate, and configure optional MCP access. |
| Migrate | Move legacy inline apps to independent V2 apps or Solutions. |
| Copilot Cowork Package | Package a Bifrost agent for Microsoft 365 Copilot Cowork. |

The plugin provides instructions for your coding assistant. Authentication and
access permissions are managed by your Bifrost instance.
