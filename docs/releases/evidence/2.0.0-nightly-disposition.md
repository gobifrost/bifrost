## Home collection cleanup

`home.admin.spec.ts` completed its drag ordering, reload, context actions,
editing and UI deletion assertions. Its independent API fixture then failed
on the first cleanup DELETE with `socket hang up (ECONNRESET)`.

The retained trace records the last setup POST response at
`2026-11-07T19:54:21.665Z` and cleanup starting at
`2026-11-07T19:54:26.665Z`. The API logs contain both successful setup
POSTs on the same connection and the successful browser deletion, but no
cleanup DELETE. The API process continued serving requests without a restart.
Uvicorn uses its default five-second idle cutoff; Playwright 1.64.1 creates
its own HTTP agent with keep-alive enabled.

The repair gives API-only fixture contexts a single-request connection
lifetime. These contexts sit idle while a separate browser session drives
the UI. Browser transport, authentication, cookies, refresh challenges and
production connection settings are unchanged. A connection reset still fails
the request; mutations are never replayed because of a network error.

A local HTTP-peer regression deterministically resets cleanup if it reuses
the setup socket. It reproduces the old fixture's ECONNRESET and passes with
the repair, with exactly one cleanup request. Another test verifies that a
mutation reset is surfaced after one attempt. The existing live Home
journey remains intact.

## Knowledge Sources namespace listing

The same run's service logs exposed a separate product error:
`GET /api/knowledge-sources` returned 500 because its repository constructor
omitted the required `org_id` argument. The repair supplies `org_id=None`
while retaining the already-authorized visibility predicate passed into the
repository query. That predicate, not a broader repository scope, continues
to determine which rows are counted.

A live endpoint regression seeds own-organization, shared Global and foreign
namespaces directly, without embedding or build jobs. It verifies successful
listing with the own and Global counts and exclusion of the foreign namespace.
