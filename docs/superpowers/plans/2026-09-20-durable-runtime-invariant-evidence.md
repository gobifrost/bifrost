## Confirmed follow-up targets

1. Add a narrow child-before-parent-wait-commit regression if reviewers want direct proof of the source race guard in `suspend_for_deferred_calls`; current evidence proves adjacent wake paths but not that exact interleaving.
2. Consider a live worker/container-loss smoke only if merge risk warrants it. Current restart recovery e2e simulates SIGKILL semantics inside the executor and validates the approved resume table, but it is not a real process/container death test.
3. If API compatibility remains a release concern, add one golden response-shape test for `GET /api/agent-runs/{id}` with a durable parent/child run rather than relying on distributed route assertions.
