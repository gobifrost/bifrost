# A2 first implementation review — corrections required

Primary inspected the first source draft before acceptance. These corrections stay within the approved A2 boundary. Do not change A1 or transport contracts.

1. `_project_tool_calls` accepts an empty journal (no legacy steps) as complete and never requires a completion event. A terminal row alone cannot prove intact history or output provenance. Require consistent durable completion evidence and contiguous sequences for every included node; missing completion, empty journal, legacy terminal output, or nonterminal child must remain incomplete. Add regression tests that a terminal row with no journal cannot pass a forbidden-tool assertion.
2. `_load_tree_ids` executes unbounded child queries, traverses hidden nodes, then loads their full rows. Expand only authorized same-tenant nodes with SQL limits before materialization. Detect withheld direct children with a bounded existence check, expose only a generic limitation, and never traverse through a withheld parent to a nominally visible grandchild. Use canonical visibility conditions per node instead of duplicating policy in `_node_visible`.
3. Journal/ledger correspondence matches only call ID without checking tool identity or duplicate ledger/call identities. Validate correspondence and avoid counting one invocation multiple times when repeated journal observations occur; preserve truly distinct repeated calls. Conflicting identity/arguments/state must not prove completeness. Document dispatch proof: failed ledger state alone is not proof of successful side effect.
4. Argument completeness is checked before final redaction. Sensitive-key redaction introduced by `redact_value` must also make argument evidence incomplete. Test a raw sensitive-key argument as well as an existing marker.
5. `_apply_usage_evidence` treats any nonempty usage subset and any known cost subset as complete, and turns missing counters into zero. Do not label partial usage complete. Establish actual recording proof or leave these dimensions false with limitations. All included nodes must be terminal with intact evidence. Reject nonfinite/negative values; do not clamp invalid negative latency to zero. A missing cost on one row must not produce a passing budget from other rows.
6. `_delegation_evidence` can recurse indefinitely on corrupt cyclic links. Bound traversal and detect cycles explicitly; no silent complete projection. Remove unused ledger_by_run structure if not needed.

Add focused tests for these conditions while completing original packet coverage. Return code plus test report to primary; no user notifications. No source edits by primary while executor is active.
