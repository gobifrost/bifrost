## Queries

Provide one shared aggregation entry point for global/admin and domain-authorized operation reports. Require explicit scope `platform` or `organization`; organization scope requires a nonnull organization UUID. No omitted-scope default that returns all tenants. Callers own actual role/domain authorization; helper must enforce the supplied scope in every usage, run and attempt query. Accept optional inclusive UTC start/end dates, source (`all`, `executions`, `chat`, `agents`), purpose, provider/model, profile identity/fingerprint, and quality-operation type/id pair. Reject half operation filters or reversed dates.

Preserve existing source semantics: executions tests execution_id, chat conversation_id, agents agent_run_id, all every row. New overhead has no AgentRun FK, so it only appears for source=all. Purpose is an independent mutually exclusive dimension. One usage row contributes once to overall totals and once to each grouped dimension; never fan-out-join usage rows to multiple domain results or historical evidence references.

Use a common SQL projection over AIUsage with at most its one-to-one AgentRun join for classification. Aggregate in SQL; do not load the complete ledger or all attempts into Python. Start/unobserved attempts without a usage row contribute coverage counts only, not artificial monetary/token rows. Use the same tenant/date/provider/profile/purpose/operation filters for attempts. Source filters other than all exclude quality-attempt gaps. Date predicates use UTC consistently and quality timestamps already equal attempt time.

## Classification

Priority: explicit AIUsage.usage_purpose; then runtime source context. Purposes for new overhead are already defined by the foundation. Existing AgentRun usage with server-reserved trigger_type=evaluation_synthetic is `test_designer` when server correlation has evaluation_designer=true, otherwise `simulation`. Do not classify production runs as testing from arbitrary correlation alone. Ordinary production agent sequence=0 is `agent_summary`; other ordinary agent rows are `runtime_agent`. Execution and conversation contexts are `runtime_execution` / `runtime_chat`. Preserve a deterministic precedence for legacy rows with multiple context FKs so purpose totals still partition overall totals. Unclassifiable rows are `legacy_unknown`.

Synthetic evaluation operation identity comes from the server-owned evaluation_execution_id correlation, validated as a UUID before exposing it as such. Synthetic descendants already carry inherited evaluation lineage and must count once through their own existing AIUsage rows. Do not separately union a parent's aggregate into the same result. Designer operation identity is its synthetic root AgentRun ID, not the placeholder evaluation_execution_id generated by the existing designer endpoint. Missing/invalid operation lineage remains unassigned (with explicit unknown coverage), never inferred from evidence source runs. Never count historical production source usage as fresh testing spend.

Quality profile identity uses persisted profile fields. Runtime profile ID comes only from immutable AgentRun execution_snapshot.model.profile_id when valid; no live profile lookup or invented historical profile name/fingerprint. Provider/model come from the actual AIUsage row. Unknown profile identity stays null. Organization display name can join the existing organization record; null/deleted scope must be represented explicitly, not reassigned to another tenant.

## Result shape and bounds

Return overall totals and bounded grouped breakdowns by purpose, provider/model, profile identity/provider/model, and organization, plus operation identity when requested. Each dimension has its own total group count, limit (default50, max200), offset, deterministic ordering, and omitted-group indicator; overall totals must never equal only the current page. No cross-product mega-table or full attempt dump. A simple shared pagination input for all dimensions is sufficient for this core; detailed browsing can be routed later.

Totals: input/output/cache_read/cache_write tokens, call_count, duration_ms subtotal and duration_missing_count, observed_provider_cost subtotal (provider_cost not null), estimated_cost subtotal (provider_cost null and cost not null), known_cost (sum of those), missing_cost_call_count, and legacy_call_count (usage_attempt_id null). Money uses Decimal, not float. Null cost contributes to missing count, not known zero. Cache fields are token sums only; do not calculate hit rate from attempts or assert provider cache semantics beyond recorded fields.

Coverage: started_attempt_count, unobserved_attempt_count, missing_cost_call_count, legacy_coverage_unknown, unassigned_operation_call_count for synthetic rows missing valid lineage. Grouped breakdowns must include groups that have only unresolved attempts, with zero observed call_count and explicit nonzero uncertainty counts. The response reports observed subtotals and tracked gaps; it must not claim all historical provider spend is complete. A zero known subtotal with unknown attempts is not a zero-cost operation.

Internal operation filters select explicit quality rows and existing synthetic AgentRun rows with the matching proven operation identity. The caller must authorize the operation before invoking this helper; R1 introduces no read surface and does not bypass source authorization. Do not change source-run cost or budget APIs.
