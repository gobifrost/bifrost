# Workspace Import Demo

`workspace-import-demo.zip` is a small Solution-format bundle intended for the
unattached **Import into workspace** flow. It carries one global workflow and
its Python source without creating a Solution installation.

The review environment is seeded with an older `workspace_import_demo`
workflow at the same path. Uploading the ZIP therefore shows both the workflow
definition and source file as conflicts. Choose **Replace all** to exercise the
complete reviewed-import path while preserving the destination workflow ID.
